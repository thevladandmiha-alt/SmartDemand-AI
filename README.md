# SmartDemand AI — учебный продукт

Прототип для доклада «Роль математических методов в работе нейронных сетей» по дисциплине «Архитектура цифровых платформ и облачные технологии».

## Запуск на Windows
1. Установите Python 3.10 или новее.
2. Распакуйте архив в папку.
3. Дважды щёлкните `start_windows.bat` (требуется интернет при первой установке библиотек).
4. В браузере откройте адрес, указанный в окне, обычно `http://localhost:8501`.

Если автоматический запуск не сработал, откройте командную строку в папке проекта и выполните:
```
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Проверка вычислений без интерфейса
`python core.py` — выводит значения MAE, RMSE и размер выборок. Требуются numpy, pandas, scikit-learn.

## Как устроен эксперимент
- 420 синтетических наблюдений с фиксированным генератором (seed 42).
- Разделение 80/20 по времени; модель не видит тестовые наблюдения при обучении.
- MLPRegressor (24, 12 нейронов), ReLU, Adam, стандартизация.
- Базовый метод: среднее продаж на обучающей выборке.
- Входы: день недели, цена, скидка, реклама. Выход: прогноз продаж.
- Синтетический процесс содержит также сезонность, которая не подаётся в модель как отдельный признак.

## Свой CSV
Минимум 70 строк, упорядоченных по времени. Столбцы: `День недели`, `Цена`, `Скидка (%)`, `Реклама`, `Продажи`. Для дней недели 0–6; реклама 0/1. На малых или нерепрезентативных выборках качество может быть низким.

## Ограничения
Прототип не развёрнут в облаке. Сценарные прогнозы не являются доказательством причинного влияния скидки или рекламы. Объём закупки не учитывает текущие остатки и логистику.
